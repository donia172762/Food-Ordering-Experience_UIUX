# 🍔 Food Ordering Experience — UI/UX Design

## 📌 Project Overview

This project is a complete **Food Ordering Experience** designed in **Figma**.

The goal of the project is to create a smooth and simple food delivery flow that allows users to discover restaurants, browse menus, customize food items, review their order, complete checkout, and confirm the order with minimal unnecessary steps.

The design focuses on:

* Attractive food presentation
* Clear navigation
* Simple ordering steps
* Consistent visual design
* Smooth end-to-end user flow

---

## 🎯 Task Requirements

The application was designed to include:

* Restaurant and food category discovery
* Restaurant details and menu browsing
* Food item selection
* Food customization
* Cart and order review
* Checkout experience
* Order confirmation
* Smooth navigation from discovery to order completion

---

## 🛠 Tool Used

* **Figma**
* Auto Layout
* Reusable Components
* Mobile UI Design
* UI/UX Flow Design

---

## 🎨 Design Concept

The application was designed as a modern mobile food delivery app called **BITE**.

A warm and friendly visual style was used to make the food experience feel inviting.

### Main Colors

* Orange — Primary actions and buttons
* Warm beige — Background sections
* Dark gray — Main text
* Yellow — Promotional elements
* White — Cards and clean surfaces

The main orange color is used for important actions such as:

* Add to Cart
* Checkout
* Place Order
* Track Order

This makes the main user actions easy to identify throughout the application.

---

# 📱 Screens

## 1. Home / Food Discovery

The Home screen allows the user to quickly discover food and restaurants.

It includes:

* Delivery location
* Search bar
* Food categories
* Promotional offer
* Popular restaurants
* Bottom navigation

Example categories:

* Burgers
* Pizza
* Healthy Food

The purpose of this screen is to reduce the time needed for users to find food they want.

---

## 2. Restaurant Details & Menu

After selecting a restaurant, the user can view:

* Restaurant name
* Rating
* Delivery time
* Delivery fee
* Food categories
* Menu items
* Food prices

Menu items are displayed using clear cards with:

* Food image
* Food name
* Short description
* Price
* Add button

A visible **View Cart** button is available after an item is added.

---

## 3. Food Item Details

The Food Item screen allows users to customize their order before adding it to the cart.

The screen includes:

* Food preview
* Food name
* Description
* Price
* Size selection
* Extra ingredients
* Quantity control
* Add to Cart button

Example customization options:

* Medium or Large size
* Extra mozzarella
* Chili flakes

This gives users control over their order without adding unnecessary steps.

---

## 4. Cart / Order Review

The Cart screen allows the user to review the order before checkout.

It includes:

* Selected food items
* Quantity controls
* Edit option
* Add more items
* Promo code
* Subtotal
* Delivery fee
* Service fee
* Final total

The **Checkout** button clearly displays the final order price.

---

## 5. Checkout

The checkout process was designed to be simple and fast.

The user can review:

* Delivery address
* Payment method
* Delivery time
* Order summary
* Delivery notes

The main checkout action is:

**Place Order**

The design avoids unnecessary pages by keeping all important checkout information on one screen.

---

## 6. Order Confirmation

After completing checkout, the user sees an order confirmation screen.

The screen includes:

* Order confirmation message
* Estimated delivery time
* Order number
* Order progress
* Track Order button
* Back to Home button

Example order progress:

1. Order placed
2. Preparing
3. On the way

This gives users clear feedback that the order was successfully completed.

---

↓

↓

↓

↓

↓

**Place Order**

It includes:

* Primary Button
* Category Chip
* Restaurant Card
* Color Palette
* Consistent typography
* Consistent spacing
* Rounded cards and buttons

Reusable components help maintain consistency across all application screens.

---

# 🧠 UX Decisions

Several UX decisions were used to improve the ordering experience.

### Clear Call-To-Action

Important buttons use the same orange color so users can easily identify the next action.

### Minimal Steps

The flow avoids unnecessary confirmation screens and extra navigation.

### Visible Prices

Prices are visible throughout the ordering flow.

### Easy Customization

Food customization options are placed directly inside the food details screen.

### Order Transparency

Before checkout, the user can clearly see:

* Food price
* Delivery fee
* Service fee
* Final total

### Order Feedback

After ordering, the user immediately receives confirmation and delivery information.
